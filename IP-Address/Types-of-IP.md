# Let's discuss about all the types of IP Addresses

## IP addresses are of several types. Here's a breakdown of the different classifications of IP addresses:

### 1. By Version (IPv4 vs. IPv6)
**IPv4**: A 32-bit numerical address written in four decimal numbers (octets) separated by dots (e.g., 192.168.1.1), providing about 4.3 billion unique addresses

**IPv6**: A newer 128-bit alphanumeric address written in hexadecimal groups separated by colons (e.g., 2001:0db8::8a2e:0370:7334), offering a virtually unlimited supply (~340 undecillion).

### 2. By Network Scope (Public vs. Private)
**Public IP Address**: Assigned by an Internet Service Provider (ISP) and unique across the entire global internet. It is used for external web servers, routers, and direct internet communication.

**Private IP Address**: Used within local area networks (LANs) like a home or office. They are not routable on the public internet and use common ranges such as 192.168.x.x, 10.x.x.x, or 172.16.x.x–172.31.x.x.

### 3. By Assignment Method (Dynamic vs. Static)

**Dynamic IP Address**: Automatically assigned to a device by a network server or router via DHCP (Dynamic Host Configuration Protocol) and changes periodically.

**Static IP Address**: Manually configured and permanently fixed to a device. It is typically used for hosting websites, mail servers, or network printers
