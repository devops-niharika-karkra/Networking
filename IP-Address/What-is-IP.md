# In this document, let's learn about IP adresses and why do we need it.

## What is an IP address?
  - IP stands for _Internet Protocol_. An IP Address is a unique numerical label assigned to each device connected to a computer network that uses the Internet Protocol for communication.

## Why do we need IP?
  - IP serves two main purposes:
    - ``Network Interface Identification``: Identifies a specific computer, phone, server, or IoT device on a network.
    - ``Location Addressing``: Helps route data packets across local and global networks to the correct destination.
